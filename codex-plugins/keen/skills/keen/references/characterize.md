# Taste and anti-slop guide

Use the generated Markdown card first and JSON only for selected numeric fields.

## Slop

Report the current score and band exactly as emitted. For no more than the top
three triggered fingerprints, state the measured evidence, why that pattern is
recognizable on this page, and one page-specific escape move. Rank by the
report's contribution value.

Do not invent fingerprints, moralize about a low score, or present surface
distinctiveness as overall usability. A score below the detector's distinctive
threshold needs no manufactured escape move.

The unit of judgment is a repeated cluster, not a lone ingredient. Inter,
Georgia, purple, rounded corners, cards, and monospaced labels can all be valid.
Explain why the measured combination is disconnected from this product's
objects, states, actions, or reading context before calling it generic.

Prefer subtraction and task structure over decorative substitution. Do not
recommend that an Inter-only page add a serif by default, that equal cards turn
into bento, that a left stripe turn into a badge, or that a quiet palette add a
complement merely to evade the detector.

## Taste

Write one compact paragraph covering only well-supported signals:

- archetype hint and palette temperature;
- hue anchor, chromatic intensity, and spread when present;
- primary type family, body size, and display ratio when present;
- radius character and shadow grammar;
- density and distinctiveness.

Treat `archetype_hint` as a heuristic. If palette or type data is missing, call
the vector thin and say which additional state or route would add signal. Do not
grade boldness as virtue or defect; taste describes, review judges.

## Comparison and remix

When comparing taste vectors, use the emitted numeric fields and
`harness.taste.vector_distance` only through a tested CLI/helper path. Do not
claim a normalized distance from hand-estimated colors.

For a remix, distinguish two proofs:

1. `validate-system --strict` proves the checks that command actually runs,
   including bundled-reference anti-imitation.
2. Inspiration distance requires explicit measured deltas from the inspiration.

If the current tooling cannot produce the second proof, report the hue/type/
shape deltas you can verify and state the limitation. Never claim a guaranteed
distance without an artifact.
