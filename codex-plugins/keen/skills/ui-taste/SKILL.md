# UI Taste

Read `../keen/SKILL.md` first, then `../keen/references/characterize.md`.

- For an HTTP(S) target, safely invoke `keen review`; it writes the taste artifacts.
- For an existing run directory, safely invoke `keen taste`.

Accept only options printed by the selected CLI command and shell-quote every dynamic value. Read `taste.md` first, then selected JSON values only when needed. Return one compact, measured characterization. Call out thin or missing signals instead of filling gaps with vibes.
