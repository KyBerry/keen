# Refine guide

Refinement covers three layers. Keep them distinct so a measured defect does
not masquerade as a taste verdict.

## Mechanical finish

Check alignment, spacing rhythm, target geometry, contrast candidates,
overflow, typography consistency, imagery quality, responsive behavior, and
captured focus/loading/empty/error states. Cite the measured evidence and its
coverage limit.

## Authorship

Check whether hierarchy, composition, copy, typography, imagery, icons, motion,
and repeated containers express the recorded direction. Call out generic AI
defaults only when they make this product more interchangeable. Explain the
specific escape move; do not prescribe ornamental variety.

## Product fit

Name the likely user and moment. Verify that reading order, supporting
information, and action weight serve the job. Some surfaces legitimately have
multiple peer actions; do not impose a universal single-CTA rule.

For each selected issue, provide the observation, user impact, contextual
judgment, correction, and verification step. When implementation is requested,
change the smallest coherent system seam, then recapture mobile and desktop
states. A source diff or passing unit test is not proof that the rendered
result improved.
