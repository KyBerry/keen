# UI Compare

Read `../keen/SKILL.md` first, then `../keen/references/review.md`.

Require one capture target and `--against`. Accept only options from `keen compare --help`. Use an exact CLI identifier: `material-3`, `apple-hig`, `fluent-2`, `polaris`, `carbon`, or `atlassian`; do not invent aliases. Safely quote every dynamic value.

Read `summary.md` and `tokens/drift.md` first, then inspect only evidence required to explain the top conformance gaps. Separate named-system drift from general UI quality and finish with the three highest-leverage corrections.
